# EU GDP Analysis 2020–2025

This project analyzes the average GDP of EU countries between 2020 and 2025 using Google Sheets.

## Tools Used
- Google Sheets
- Basic formulas
- Data visualization

## What I Did
- Collected GDP data for EU countries from 2020 to 2025
- Calculated the average GDP for each country
- Converted large numbers into trillion USD
- Created a clean table for comparison

## Key Insight
Germany had the highest average GDP among the selected EU countries during 2020–2025.

## Dataset
The data was organized and cleaned in Google Sheets.
